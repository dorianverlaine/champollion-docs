Champollion 是一个用户态的 RISC-V（RV64GC）Linux 二进制翻译器。程序以普通宿主进程的身份运行：
没有虚拟机启动，也没有客户机内核垫在下面，程序发起的 Linux 系统调用由翻译器处理，或者转发给宿主。

```console
$ rvrun tests/fixtures/hello
hello from riscv64
```
