Champollion 是一个用户态的 RISC-V（RV64GC）Linux 二进制翻译器。程序以普通宿主进程的身份运行：
不会启动虚拟机，也没有客户机内核；程序发起的 Linux 系统调用由翻译器处理，无法处理的则转发给宿主。

## 📌 状态

M5 已完成，VM 模式的达成标准也已满足：riscv64 容器镜像可以在 Mac 上运行，Alpine 与 Debian 的
根文件系统中也可以运行 `apt`、CPython 等程序。[项目状态](/zh-CN/project/status/) 列出了已经能用的部分、
