Champollion is a user-mode RISC-V (RV64GC) Linux binary translator. A program
runs as an ordinary process on the host: no VM boots, no guest kernel sits
underneath, and the Linux system calls it makes are served by the translator or
forwarded to the host's.

```console
$ rvrun tests/fixtures/hello
hello from riscv64
```

M5 is done, and route A's done criterion is met: riscv64 container images run
on the Mac, and Alpine and Debian roots run `apt`, CPython, and friends.
